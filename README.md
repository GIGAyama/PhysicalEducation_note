# 体育ノート (Physical Education Note)

[![GIGA Standard v2 Compliant](https://img.shields.io/badge/GIGA%20Standard-v2-blue.svg)](#)

「体育ノート」は、公立小学校向けの体育授業向けクラウド型振り返り・目標設定Webアプリケーションです。  
GIGAスクール構想下の1人1台学習用端末（Chromebook等）での利用を前提に設計されており、Google Workspace for Educationの環境下でセキュアかつシームレスに動作します。

## 🌟 特徴 (Features)

### 👧👦 児童向け機能（Student View）
*   **直感的なUI**: 小学生が迷わず操作できる、大きめのボタンと学年配当漢字を意識したインターフェース。
*   **「めあて」と「振り返り」のルーティン**: 授業前に「知る・見る・する・支える」の4観点からめあてを選び、事後に振り返りとコメントを記録。
*   **ポートフォリオ機能（マイ・ポートフォリオ）**:
    *   **レーダーチャート**: 自分がどの観点の学習を多く選択しているかが一目でわかるバランス分析。
    *   **タイムライン**: 過去のめあてや振り返りを時系列で振り返る振り返り支援機能。
*   **サンクスカード**: 友達への感謝や称賛のメッセージを送り合うピア・サポート機能。
*   **お手本メディア閲覧機能**: 先生が設定した各時間の「お手本動画やスライド」をシームレスに閲覧可能。
*   **スマートな学習再開**: アプリを開いた瞬間に、「前回の続き（次に取り組む時間）」が自動的に選択されるUX設計。

### 👨‍🏫 教員向け機能（Teacher View）
*   **単元マネージャー**: 複数の単元を並行して作成・管理。各時間ごとの「めあて」や「お手本メディア（Google ドライブの画像や動画、スライド）」を柔軟に設定可能。
*   **リアルタイム学習状況把握**:
    *   児童一人ひとりの「本日のめあて」「振り返り内容」「未入力アラート」を一覧表示。
    *   特定の観点ばかりを選んでいる児童に対する「偏りアラート」機能。
*   **クラスポートフォリオ（全体分析）**: 
    *   クラス全体の観点選択バランスをレーダーチャートで可視化。
    *   過去2週間の振り返り提出推移を棒グラフで表示し、クラスの「スポ活」への熱量を把握。
*   **個人カルテ（詳細分析）**: 
    *   児童ごとの詳細なログ履歴と、もらったサンクスカードを閲覧して声かけや評価（所見）に活用。
*   **CSV一括ダウンロード**: クラス全体の記録をCSV形式で保存し、学期末の評価資料として活用。

## 🛠️ 技術スタック (Tech Stack)

*   **バックエンド**: Google Apps Script (GAS)
*   **データベース**: Google Spreadsheet
*   **メディアストレージ**: Google Drive
*   **フロントエンド**: HTML5 / CSS3 / Vanilla JavaScript / Bootstrap 5 / Chart.js リソースベース / SweetAlert2
*   **デプロイ**: clasp (Command Line Apps Script Projects)

## 📦 インストールとデプロイ (Installation & Deployment)

1.  **リポジトリのクローン**
    ```bash
    git clone https://github.com/GIGAyama/PhysicalEducation_note.git
    cd PhysicalEducation_note
    ```

2.  **claspのログインとプロジェクト作成**
    ```bash
    clasp login
    clasp create --type webapp --title "体育ノート"
    ```

3.  **ファイルのプッシュ**
    ```bash
    clasp push
    ```

4.  **ウェブアプリとしてのデプロイ**
    ```bash
    clasp deploy
    ```

5.  **アプリの初期化**
    *   デプロイされたウェブアプリのURLにアクセスします。
    *   初回起動時は「初期化セットアップ」ボタンが表示されるので、クリックしてデータベース（スプレッドシート）とお手本フォルダを自動生成します。

## 🔒 セキュリティとプライバシー (Security & Privacy)

*   **Zero Trust Architecture**: 教員・児童のGoogleアカウント認証によって完全に保護されており、許可されたユーザー（ドメイン内）のみがアクセス可能です。
*   **自己修復機能（Auto-Recovery）**: データ基盤であるスプレッドシートやメディアフォルダが誤って削除された場合でも、システムが自動的に新規作成して復旧します。
*   **XSS対策**: ユーザー入力（振り返りコメントやサンクスカード）を表示する際は、厳密にHTMLエスケープ処理を実施しています。

## 📝 開発ルール (Development Guidelines)

本プロジェクトは以下のルールに基づき開発されています：
*   **児童目線のUI/UX**: 子供の主体性を引き出すための「直感性・可読性・安全性・反応性」を優先。
*   **実戦的実装**: 学校現場の回線や端末スペックを考慮した、負荷の少ない設計とエラーハンドリングの徹底。
*   **個人情報ゼロトラスト**: 児童の個人名を必要以上に外部に出さず、セキュアなGoogle環境内で完結。
